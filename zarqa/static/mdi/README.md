# Icons

A subset of [Material Design Icons](https://github.com/Templarian/MaterialDesign) 7.4.47 (licence in
`LICENSE`): only the icons the UI uses, in one woff2 file. `scripts/build_icons.py` rebuilds it from the
full `@mdi/font` package after a new icon is used; `tests/test_icons.py` fails when one is missing.
